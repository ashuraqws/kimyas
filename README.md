# Element Çarkı — Periyodik Sistem

9. sınıf kimya dersi için hazırlanmış interaktif periyodik sistem uygulaması. Çarkı çevir, rastgele bir element keşfet ve kimyanın dünyasına biraz daha yakından bak.

## 🔗 Siteyi aç

**https://ashuraqws.github.io/kimyas/**

## Özellikler

- 118 elementlik dönen çark ve seçilen element için keşif animasyonu
- Her element için bilgi kartı: genel bilgi, temel özellikler, kullanım alanları, günlük hayat ve ilginç bilgi
- Gerçek yerleşimine uygun periyodik tablo; arama ve kategoriye göre filtreleme
- Açık / koyu tema
- Telefon, tablet ve bilgisayarda çalışır; internet bağlantısı gerektirmeden tek dosyadan açılabilir
